On the package settings page, they should find either Manage access or Inherited access. GitHub uses different wording depending on whether package permissions are independent or inherited from a repository.

If it says “Manage access”

The package has its own permission list.

If it says “Inherited access”

The package inherits permission from a linked repository.

The owner should identify which repository is linked to the package. If the package is supposed to inherit from the repository containing the Wlf.Identity.IntegrationEvents source code, they should verify:

Inherit access from repository: enabled
Linked repository: the correct Identity repository
Your account/team: Read access to that repository

GitHub says a user with Read access to a linked repository should receive Read access to the package when inheritance is enabled.
